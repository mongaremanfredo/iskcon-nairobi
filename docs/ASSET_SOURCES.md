# Asset Sources

Most active homepage and project imagery now uses temple-provided files gathered
during the build: ISKCON Nairobi aerial views, altar photos, Kirtan Safari
artwork, HKTC photos, leader portraits, Thika farm images, Food For Life images,
and community portraits.

The following library assets remain in the repository for context-specific pages
where final temple photography may still be added later.

| Asset | Source | Current use |
|---|---|---|

| `/images/community/iskcon-temple-architecture.jpg` | Wikimedia Commons, ISKCON Temple Bangalore | Generic ISKCON temple architecture for pages that still need final temple-specific photography |
| `/images/food-for-life/khichdi-prasadam.jpg` | Wikimedia Commons, Khichdi Prasadam at ISKCON Bangalore | Hidden shop route and prasadam support imagery |

| `/images/guest-house/temple-view-room.jpg` | Pexels hotel bedroom image | Guest house room card |

Before a final client handoff, verify licensing for any library asset that will
remain public long term. When real ISKCON Nairobi photography becomes available,
replace the library asset at the same public path only if the framing remains
compatible with the existing component.
